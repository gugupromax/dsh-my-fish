# My Fish 迁移说明

0.4.0 起统一使用 My Fish、包/模块 dsh-my-fish、主 API /my-fish/api。旧 X 工具及旧路由保留升级兼容。

公共默认角色采用可编辑的 [中性模板](ROLE_TEMPLATE.md)。已有个人角色继续留在本地工作区，改名、升级或准备公开源码时不导出其内容，也不以公共模板覆盖本地设置。

新数据目录优先；只有旧目录时原位兼容，不复制/合并 DPAPI 凭据、记忆或会话。沿用 state 中主会话，不从文档重建。

安装器先准备项目依赖，再显式 migrate-legacy 在同一 profile 替换旧包；拒绝默认双加载。实际用户 profile 升级未在本轮执行。详见 UPGRADE_MY_FISH.md。

本轮未修改其他项目、真实账号或任务账本。旧本机文档证据保存在私有 recovery，不加入公开发行。
