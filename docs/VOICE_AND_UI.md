# My Fish 入口与语音

0.4.0 使用已核实的 DSH 0.2.1-rc.3 前端接口。

- sidebar.footer.action 追加常驻 My Fish，位于账号区附近，不覆盖官方账号/设置入口。
- 已有主会话直接 openSession；首次可信 POST session 只创建一次，不 prompt、不计探索次数。
- 设置包含角色/记忆/目标/动态、手动任务、通用计划及独立权限。
- 公开角色只提供通用 My Fish 模板，个人称呼、人设和兴趣由使用者在本地填写；示例和界面验证不使用个人设定。
- 表单未保存保护、定时刷新与失败分别显示，不把错误覆盖为空数据。

## 官方听写

打开固定主会话，用官方输入听写。识别文字进入草稿，用户确认后发送。设置只读查询 speech.catalog 并解包 Remote Result，不开启麦克风或下载模型。

官方录音没有本版已核实的公开触发方法，不覆盖其单槽控件。本版没有独立录音、TTS、连续轮次或打断，不把听写称语音通话。
