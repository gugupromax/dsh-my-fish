# My Fish 权限与数据

可信本机设置页保存权限；角色、记忆、任务及网页不能改变开关。

0.5.0 的渠道目录和新 social_timeline/social_comments 仍走相同主会话/计划作用域。只读计划可以读取已声明支持的公共内容，仍不能执行social_action。B站不提供任何外部写动作，不继承X的动作开关；匿名请求不读取Cookie、上游账号或私人角色。宿主搜索桥接保留当前agent、取消信号和真实parent token，内层调用继续经过宿主守卫，不能用definition.execute旁路。

公开仓库仅提供 [通用角色模板](ROLE_TEMPLATE.md)，不发布个人名称、人设、固定私人称呼、兴趣或关系设定。个人角色和私密词等运行配置保存在本地工作区；发布检查必须覆盖源码、示例、文档、截图与最终文件清单，不能只依赖 Git 忽略规则。

0.4.1 的完整工作区迁移只接受可信设置页的明确目标。个人模型工具不能修改资料路径。迁移使用主会话 maintenance 独占并暂时阻断个人工具和本插件设置写入；有未恢复事务时继续禁写，直到校验恢复成功。原目录保留备份，DPAPI 仅复制加密字节。路径切换不更改宿主原始权限根或项目归属，不能暗中启用完全访问模式。

| 权限 | 默认 | 范围 |
| --- | --- | --- |
| 本机代码/命令/终端 | 关闭 | pwsh/bash/terminal_open/send/run_code |
| 本地文件写入 | 关闭 | write/edit，宿主仍限制路径 |
| 浏览器交互 | 关闭 | bsk_interact/bsk_assist |
| 委派 | 关闭 | subagent/spawn_teammate/send_message，归属服务不可用拒绝 |
| X 收藏/回复/公开 @ | 关闭 | 主会话、目标证据、额度、去重和回执 |

主会话及真实 AgentRegistry 核对活跃所有权的子孙进入 guard。计划及其子孙固定只读，不继承个人记录、机器执行或社交写入。普通 DSH 会话继续使用自己的宿主权限。

未分类工具在个人范围拒绝。工具可见、连接、审批由宿主决定，不以 CLI 存在当成可用。

## 宿主交互与上下文工具

0.6.5另补齐个人范围grep与task_board_get。grep原生实现为固定ripgrep参数读取，但使用unconfined subprocess，源码没有文件根检查，因此不向计划开放；不声称它由宿主限制在工作区内。task_board_get返回完整正文、执行记录及关联子卡，不向计划开放。未知工具拒绝信息附运行版本和规则号，相关元数据在模块加载时固定。

计划使用显式native的专用预设，挂载读取/网页工具；作用域掩码隐藏已知全局私有与写工具，模型直接看到原生读取及报告入口。run_code即使传空程序也拒绝执行；没有把“PTC内层只调用只读工具”当作脚本沙箱保证。此前四个工具再次被报unknown时，须核对加载版本或报错轮次，不能据进程存在直接断定已加载新代码。
0.6.4按实际定义补齐四个精确工具名，不以通用前缀或取消未知工具守卫代替分类，也不写入或开启使用者权限开关：

| 工具 | 主会话和真实个人子孙 | 定时计划及其子孙 |
| --- | --- | --- |
| ask_user_question | 宿主提问交互 | 问题改用assistant_plan_report回流，不弹交互提问 |
| session_event_search | 历史读取，目标仍经宿主授权 | 仅缺省当前会话或session_id精确为调用者自身 |
| task_board_list | 只读列看板任务 | 拒绝，避免读取其他个人卡片 |
| compress | 维护当前会话上下文 | 允许维护当前执行上下文 |

ask_user_question经宿主userQuestions服务提问，不属于命令、文件写入或公开社交操作。session_event_search原生接口允许查询同原始目录的其他已授权会话，计划额外收窄至自己；不会因此主动扫描旧聊天，未来消息观察的边界保持。task_board_list能跨卡片列出和检索，不能简单给计划视作无范围的公共读取。compress的已安装定义来自billion-context，修改当前上下文；它的可选外部摘要仍使用使用者既有配置，分类不证明真实压缩或摘要连接成功。

decompress可能导出到任意toFile路径，未随本次放行；task_board_create/update/archive/run等写动作和其他未审查工具仍被拒绝，应继续用受限assistant_plan管理本插件计划。已退休主会话及其子孙仍全部撤权，普通会话不受插件新增限制。内层宿主工具可见性、参数校验和会话访问检查继续适用。

## 外发检查

受控查询、网页 URL、浏览器参数及社交正文检查用户私密词、常见凭据和本机/共享路径，支持规范化和多层 URL 编码。命中即拒绝，不擅改后发，不在错误回显秘密。

规则不是全面防泄漏系统，不保证识别所有个人信息、语义或编码。私密词存在用户数据 assistant/permissions.json，模型状态仅返回规则数量。不要填写 Cookie、密码或密钥。

## 保证的限制

允许命令、代码或通用浏览器交互后，可通过其他路径对外操作；本插件不能保证拦截全部间接社交写入。X 开关不是全机权限。宿主范围、审批和系统约束始终适用。

run_code 可直接调用 Node，归机器执行，默认拒绝。内层工具过 guard 不表示整个代码程序受控。推荐个人和计划使用原生工具。

宿主 guard 缺失时界面提示，不能靠角色规则声称控制其他工具。完整桌面控制未实现。

## 数据和回执

X 写入限定主会话、已读目标、核对账号/开关/额度/间隔和去重；无可靠回执锁定 uncertain，不自动重发。动态盒只写本机，不发帖或 @。公开写尚未真实验收。

新 my-fish 优先，只有旧 x-whale 时原位兼容，不自动合并。Windows Cookie 用当前用户 DPAPI，不回显，不读日常浏览器凭据；其他系统文件权限不称同等加密。

忘记仅删除独立库条目，不删除旧聊天、日记、证据或备份；旧日记不恢复成事实。

发行排除用户 config/credentials/state、个人库、浏览器配置、recovery、缓存和历史包。发布前检查公开清单。

## 验证

合成回归覆盖默认权限、编码敏感内容、活跃子孙继承、普通隔离和只读计划。真实 Tools/AgentRegistry 隔离验证覆盖实际执行入口、嵌套 prepare、注销；没有运行模型、用户命令或 PTC 程序。长期及公开写仍待验收。
