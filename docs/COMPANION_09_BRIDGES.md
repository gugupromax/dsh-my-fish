# My Fish 0.9 陪伴接驳

开发预览：代码、合成验证和真实运行分别说明。桌宠及视频是可选上游插件接驳，不是已在本机部署完成的能力。主会话、人设、记忆、账号和精确计划继续独立管理。

## 入口

完整退出重开DSH后，在My Fish“设置→陪伴能力”点击读取本地设置。内部小标签分别为桌宠与语音、视频理解、RSS来源；切换不保存、不安装、不联网或播放音频，草稿保留。所有新增开关默认关闭。日常B站链接增加“看片段”，开启视频读取后将明确请求交到同一个main，不创建新角色或后台视频任务。

## 桌宠

可选消费 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的公开HTTP接口。只允许可信WebServer.getOrigin返回的本机HTTP实例，不允许自由配置目的URL。用户选择已存在petId与web/desktop显示端，指定文字broadcast和动画；不调用桌宠chat/whisper模型或读取其记忆/账号。

仅未来固定main的已提交model助手消息有资格表达；中断、程序投递、其他会话、重复消息、疑似敏感或超过1600字的回复跳过。消息ID持久去重（上限5000，满后不转发）；lock→broadcast→可选池内anim→释放，租约丢失/取消/结果未知不重试。只清自有气泡、释放自有锁，不强抢其它插件。check仅显式GET /state并投影已有状态的宠物ID，不返回余额、历史或配置路径，也不是完整宠物目录。

上游HTTP控制与Cordis状态/扩展服务不同。API受理不等于画面已显示或声音已播放；当前上游接口不保证停止已播放音频。桌宠需单独安装、选择和配置；关闭它自己的独立聊天/碎碎念等来源应由实际部署时核对，避免第二套角色。

## 轻量本地朗读

使用浏览器Web Speech API，不依赖语音女友的WSL、GPU、声音克隆或数字人组件。严格选择localService===true且中文的音色；没有即明确不可用，不回退云语音。已提交短回复分句排队，代码与链接简化，长于1600字不自动播报。此模式不是连续听音或VAD插话；麦克风和官方听写控件不被覆盖。

后台只提供有界内存队列，主会话换绑/用户新消息/停止/改模式递增epoch清队列。常驻侧栏消费者只领取当前main，首次与重新显示不补播旧回复，四秒单消费者租约防双页回声。输入、页面隐藏、停用、失去租约或连接超时取消自身待播及utterance；没有持有自己的播报时不取消其它声音。保存开关不证明实际出声，需用户点试听验证系统音色及浏览器策略。

## 视频片段

参考 [dsh-video-storyboard 0.7.4](https://github.com/SAOS-3624/dsh-video-storyboard) 的公开工具契约，不复制代码或启动其安装器。assistant_video仅当前main明确启用并调用，接受规范BV/YouTube HTTPS链接，无本机路径、cookie参数、自由工具名或命令。默认90秒，上限180秒，从video_probe到限额storyboard，固定最多12帧、2图及低清扫描。

调用完整保留真实parent/token/rootCallId/agent/toolSet，只有本次对应阶段的精确嵌套调用可放行；直接video_*、后台与计划不因此获得新执行权限。宿主图片附件引用由原生output.render保留为image+attachment；文件路径不算图片。字幕缺少结构化证明时hasTranscript=null，图片返回也不证明像素被当前模型接收；纯文本模型仍需另配真实读图能力。

**allowAnonymous不强制匿名。** 上游可能沿用其配置的Cookie、下载器和ASR服务；用户开启时应理解这一点。My Fish不读取、复制或自动迁移这些凭据。停止按钮只停止等待和结果交付，不承诺杀掉不配合的上游下载/转写进程；busy保留到请求结束，期间不重开，并阻止工作区迁移/主会话换绑。关闭授权会中止本插件等待，不自动重复下载。

成功read可保存来源和明确覆盖范围的回执；probe不算阅读。失败时不编造经历；本地回执保存失败仍返回实际结果，避免诱导重复请求。固定请求ID的“看片段”投递与普通链接聊天、猜评论各自有独立指纹，未知不重发。

## RSS

独立实现通用RSS/Atom，不复制乔木RSS的GPL代码、不使用其服务或公开改写入口。设置每行公开HTTPS源，可写“名称 | URL”。最多20源，ID从规范URL生成；默认无源，启用后才纳入已开启的自主探索，不自动开启作息。

HTTPS443、无凭据/敏感查询，DNS所有地址均需公开并固定TLS连接lookup，无重定向、无Cookie/Authorization，512KiB与15秒上限。XML tokenizer限制深度/节点/UTF-8，拒绝DTD/外部实体，不执行HTML。当前仅支持未压缩UTF-8 XML；不支持格式明确失败。

discover轮换已配置源，只生成候选；read仅本会话最近发现、15分钟内且未改源的缓存内容。实际读到的是feed内正文或摘要，不抓文章外链，也不声称听播客或看视频。证据保留实际范围与截断。生产只向main和已登记探索会话开放配置源，普通会话/计划不继承来源。背景按所选渠道限定工具与额度，来源轮换不依赖30条历史保留长度，避免RSS饿死。

## 部署检查与隐私

`node scripts/check-companion-deps.mjs --profile desktop`只读所选profile包元数据和PATH工具存在性，不读取人设、历史、凭据、不安装。包声明/缓存存在不等于已启用、当前模型可用或真实执行成功。

2026-11-14本机部署：用户明确授权后，通过当前DSH官方插件管理接口向desktop安装dsh-pet 0.4.8和dsh-video-storyboard 0.7.4，原依赖版本及既有bundle选择保留。修改前的profile文件、原媒体环境变量与My Fish接驳设置均存放于DSH_HOME下的私有备份，不进入源码。另安装用户级FFmpeg 9.0.2（含ffprobe）和yt-dlp 2026.10.26，并设置DSH_FFMPEG_PATH/DSH_FFPROBE_PATH/DSH_YTDLP_PATH及DSH_HWACCEL=none。未下载实际视频、未配置账号/Cookie/ASR。

本机已开启手动视频入口和pet=main/surface=web的无声气泡联动。桌宠设为DSH页面内显示，关闭余额轮询、自动碎碎念、通知、声音及独立桌面助手；没有额外下载Electron桌面运行时。上游手动聊天、睡觉梦话仍是它自己的模型功能，本桥接不调用；不能将关闭碎碎念解释为整个上游永久禁止模型调用。RSS原设置保留，浏览器朗读未自动启用。源码发行仍默认关闭，不将本机设置当作其他用户的默认值。

新环境变量须由完整退出后重新启动的DSH继承；旧终端/受限进程的PATH检查仍可能显示未检测到，不能据此重复安装。检查脚本只报告当前进程PATH，不读取用户注册表。不要照抄旧上游README的desktop路径；先核对当前宿主CLI和同profile。

assistant/integrations.json与presentation.json只留用户工作区，随迁移复制，Git与公开包排除。语音队列及消费者租约在内存；持久记录只有设置与消息ID/受理状态，未知不当作发送失败重投。新功能不修改旧人设、记忆或账号权限。

## 验证

`npm run check`共530项通过，安装版生产root链等14个隔离脚本全部通过。专项使用临时数据、合成网络/宠物/语音引擎；生产root链验证视频默认关闭、允许嵌套来源与限额、原始视频工具仍拒绝、附件原生render及无损JSON；真实已提交助手事件→浏览器队列→stop epoch也经同一API验证。

另有两个需已安装可选依赖的显式检查，不纳入默认回归：

- `scripts/verify-pet-runtime.mjs`须用DSH自带运行时及`--expose-internals`执行：实际PluginPackages解析钩子、原安装包、临时DSH_HOME，验证state→lock→broadcast→clear→release；无改写上游代码，模型/网络/凭据/子进程均为0。裸Node缺少宿主解析钩子时无法直接加载Host peer，不应据此重装依赖。
- `node scripts/verify-media-runtime.mjs`须在当前进程提供核验过的DSH_FFMPEG_PATH和DSH_FFPROBE_PATH：临时生成3秒测试图视频，实际调用0.7.4引擎，产出798×241 PNG并再次解码为RGB像素验证；网络/模型/ASR均为0，临时数据清理。没有读取用户视频。

真实桌宠DOM、气泡视觉、音色、RSS站点、远程媒体下载/转写与聊天体验仍需重开后验收。实际本地抽帧不证明下载成功，合成附件引用与实际PNG均不证明像素已进入当前聊天模型。本次没有启动真实profile，以免触发用户原有计划或自主探索。
