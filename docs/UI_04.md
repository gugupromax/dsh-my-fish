# My Fish 0.4 界面与语音边界

## 固定入口

产品和设置入口名为 **My Fish**，前端模块为 `dsh-my-fish`。公共默认角色使用中性 [My Fish 模板](ROLE_TEMPLATE.md)；个人角色名、人设、称呼和兴趣在本地独立保存，不写入公开示例。

通过宿主的 `sidebar.footer.action` 列表槽，在账号区域上方增加常驻按钮。宽侧栏显示“鱼 My Fish”，窄侧栏保留图标、提示与无障碍名称，不覆盖宿主账号/设置入口。

0.4.2 起所有聊天入口先调用 POST session 核验宿主记录，再通过公开 uiWorkspace.openSession 打开返回的会话。无有效记录时，人工点击可恢复为新空会话，保留个人资料；临时异常不替换，归档记录仍保留。并发入口共享正在进行的检查，后端持久创建请求避免重复建立。初始化不投递模型任务、不创建计划，不恢复已删除聊天。

设置页已有的“和她聊天”保留草稿保护：角色、作息、平台配置、个人权限，以及尚未提交的临时任务、记忆、目标和计划有草稿时，先保存或清空。原有会话导航失败会保留设置页并显示原因。

设置等待异步导航成功后才关闭；导航失败不触发第二次重建。恢复后如原自主跟进已启用，显示暂缓提示和独立“恢复自主跟进”，只解除这项恢复暂停，不修改账号限流、社交开关或不确定回执，也不立即投递任务。旧未完成轮次展示“已中断”。

## 自定义工作区与自动迁移

“工作区”展示后端确认的个人资料位置和会话工作目录。用户输入新的绝对路径后点击“保存并迁移工作区”，由后端完整搬迁本插件的角色、记忆、目标、配置、加密账号资料及工作文件。目标目录已有内容时拒绝覆盖，旧位置保留备份；DSH 聊天历史由宿主继续保管，同一主会话使用新的工作目录。

同一台电脑、同一系统用户下，加密文件原样迁移，不要求重新登录；不保证跨系统用户可解密。迁移前先停止正在运行的任务，是否允许迁移以实时后端状态为准。

工作区区块始终提示：切换原会话实际工作目录不会改变 DSH 原会话的文件权限或项目归属，命令和文件操作继续遵循宿主权限与审批。后端可以返回 `permissionBoundaryUnchanged: true` 表明此边界，界面不会把迁移成功解释成扩权。

工作区状态独立读取。失败会显示错误并保留上次已知位置和路径草稿，不用空字符串或默认位置替代真实配置。刷新保留未保存路径；路径草稿与其他设置一样，阻止直接唤醒和通过“和她聊天”关闭设置。可以取消修改恢复当前路径。

保存期间显示迁移状态并禁用设置操作和输入；后端报告正在迁移时同样禁用。迁移成功后采用后端返回的资料位置和工作目录，清除已保存路径的草稿标记；失败时保留原路径和目标草稿，显示原因，不声称成功。

界面接口为 `GET workspace` 与 `POST workspace {path}`。具体数据完整性、主会话目录切换和回滚由后端实现与隔离迁移测试核验；本轮客户端测试只使用合成位置，没有搬迁用户真实资料。

## 定时计划

界面调用后端的宿主任务看板桥接，不维护第二套计时器。提供：

- 每小时整点、每天指定时间、一次性计划；周期计划保存明确时区，一次性输入按当前客户端本机时区转换为绝对时间。
- 新建、暂停、恢复、取消，以及修改执行时间。
- 修改时间保留原暂停开关和次数上限。执行要求保留；要改变任务内容，取消旧计划后新建，避免混淆历史记录。
- 显示下一次时间、宿主实际执行结果和错误、最近执行历史，以及安静汇报、通知和去重状态。
- 没有任务看板时显示具体不可用原因，个人记忆、角色和平台设置仍可使用。

同一次新建的连接中断重试保留请求标识和原草稿，便于后端幂等核对。保存成功只表示计划已保存；界面不会把它显示成已执行。暂停只停止未来触发，当前轮需在宿主会话中停止。错过的触发沿用任务看板“不补跑”语义。

本版计划是独立只读执行，不继承主会话的个人记忆和社交写入权限，也不提供计划脚本执行器。

## 个人工具权限

本机命令、代码与终端，本地文件写入，通用浏览器交互，子任务委派分别配置，默认关闭。私密词组按行保存，空行会在保存前清除。角色、作息、平台社交开关与这些权限分开保存。

界面显示宿主工具门禁是否可用。缺少门禁时提示先检查插件加载，不宣称已技术拦截所有宿主工具。命令、代码和浏览器交互可能间接产生外部操作；这些能力打开后仍受宿主权限约束，也不能据此保证拦住所有间接社交写入。

## 官方语音输入

保留官方会话输入框听写流程：先打开 My Fish 固定会话，再使用官方录音按钮；识别结果进入可编辑草稿，由用户检查后发送。

设置页“检查听写服务”仅调用公开的 `speech.catalog()`，按宿主 Remote 的 Result 解包，显示提供方及资源准备状态。此按钮不申请麦克风、不录音、不准备或下载模型、不提交任务。

实际安装源码只公开官方客户端的 `apply` 与 `inject`，没有根级公开录音触发服务。My Fish 不模拟点击官方内部控件，也不占用官方 `conversation.input.activity` 单槽。TTS 回复朗读、连续语音轮次和打断播报尚未接入。
